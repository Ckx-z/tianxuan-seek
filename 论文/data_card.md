# 数据卡片 — FluoroFilm v5 训练数据

## 概述

本数据集用于训练 GNN 模型预测亚胺键 COF 单体对的成膜概率。包含 6,201 条醛-胺配对样本，每条样本带有 0.0 / 0.7 / 0.8 / 1.0 四级连续标签。

---

## 数据来源

### 文献提取（v3_db_full，848 条）

- **原始文献**：~840 篇 COF 相关 PDF 论文
- **提取方式**：MiniMax API / MiMo Omni 多模态 LLM 结构化提取
- **提取内容**：醛/胺单体 SMILES、名称、投料比、溶剂、温度、催化剂、合成路线、界面类型、是否成膜、膜质量
- **提取时间**：2025-2026 年，分 v2/v3 两个阶段
- **文献覆盖**：357 篇独立论文，848 个配对组

### 正样本增广（augmented_v4，1,308 条）

- **生成方式**：基于文献中确认成膜的配对，通过单体替换生成衍生正样本
- **策略**：替换醛或胺为结构相似的单体，保持化学合理性
- **标签**：统一标记为 0.7（弱正信号，低于文献确认的 1.0 和粉末合成的 0.8）

### 化学规则负样本（4,173 条）

| 子类 | 数量 | 规则描述 |
|------|------|----------|
| hard_rule_sampled | 3,104 | 硬规则确定性负样本（官能团不足、拓扑不匹配等） |
| chem_rule_L2_multi | 265 | 双官能团多取代边界 |
| chem_rule_L3_multi | 235 | 三官能团多取代边界 |
| chem_rule_symmetry | 132 | 对称性违规 |
| chem_rule_L4_multi | 132 | 四官能团多取代边界 |
| chem_rule_steric_block | 66 | 位阻效应 |
| chem_rule_L5_multi | 36 | 五官能团多取代边界 |
| chem_rule_weak_nucleophile | 31 | 弱亲核胺 |
| chem_rule_excess_fluoro | 22 | 过量氟取代 |
| chem_rule_flex_rigid_extreme | 22 | 柔性-刚性极端失配 |

## 标签定义

| 标签值 | 含义 | 判定标准 |
|--------|------|----------|
| **1.0** | 确认连续成膜 | 文献明确报道形成连续 COF 薄膜 (is_film=True) |
| **0.8** | 粉末合成 | 成功合成 COF 但为粉末/微晶，非连续膜 (is_film=False 但 film_quality 有值) |
| **0.7** | 增广正样本 | 基于文献正样本化学衍生，非实验验证 |
| **0.0** | 负样本 | 化学规则判定不成膜 或 文献内与成膜配对同 paper 的未成膜记录 |

**标签是连续值而非离散类别**，训练使用 FocalLoss 连续版本：$p_t = 1 - |y - \hat{y}|$。

## 数据构建流程

```
原始 PDF (~840 篇)
    │
    ▼ LLM 结构化提取 (MiniMax / MiMo)
v3_db_full (848 条文献配对)
    │
    ├──→ 正样本 (is_film=True, 429 条) ──→ label=1.0
    ├──→ 粉末样本 (is_film=False, film_quality 有值, 291 条) ──→ label=0.8
    └──→ 混合文献负样本 (同 paper 有成膜, 128 条) ──→ label=0.0
    │
    ▼ 正样本增广
augmented_v4 (1,308 条) ──→ label=0.7
    │
    ▼ 化学规则负样本生成
hard_rule_sampled (3,104 条) ──→ label=0.0
chem_rule_* (941 条) ──→ label=0.0
    │
    ▼
v5_train_stage1.csv (6,201 条)
```

## 数据清洗记录

### 修复 1：删除假负样本（2026-06-05）

- **问题**：v3_db_full 中 1,406 条 label=0.0 来自 777 篇纯负样本文献（从未成膜也从未出粉末），这些不是真正的负样本
- **处理**：删除，仅保留 128 条来自 62 篇混合文献的负样本（同文献有成膜记录的才是可靠负样本）
- **影响**：7,607 → 6,201 行

### 修复 2：CV 泄漏（2026-06-05）

- **问题**：合成样本共享 paper_id（hard_rule_sampled 3,104 条共享一个 ID），文献级 StratifiedKFold 将其全部分入同一 fold
- **处理**：每条合成样本分配独立 paper_id（hr_xxx / aug_xxx / cr_xxx）
- **影响**：独立 paper_id 从 ~400 → 5,710

---

## 数据拆分策略

- **方法**：StratifiedKFold（5 折 x 3 重复）
- **分层依据**：`paper_id`（文献级拆分，严禁随机打散）
- **原因**：同文献的多个配对共享实验条件，分散到不同 fold 会导致标签泄漏
- **标签分层**：按 `is_film` 四类标签分层，保证每折标签分布一致

## 已知偏差与局限

1. **文献正样本偏袒**：文献倾向于报道成功案例，正样本覆盖的化学空间可能偏窄
2. **负样本来自规则而非实验**：4,173 条负样本中仅 128 条来自文献记录，其余为化学规则生成，可能遗漏某些不成膜模式
3. **粉末标签 0.8 的主观性**：0.8 是介于成膜和不成膜之间的折中标签，其赋值基于「有粉末=成功合成但未成连续膜」的假设
4. **LLM 提取误差**：SMILES 和结构化信息由 LLM 从 PDF 提取，存在解析错误（已人工抽检但未全覆盖）
5. **化学空间覆盖**：954 种醛 x 1,415 种胺仅覆盖亚胺键 COF 的一小部分，模型对新颖结构的泛化能力有限
6. **时间偏差**：文献覆盖时间跨度大，早期文献的实验条件和表征手段与现代不同

---

## 使用限制

- **仅适用于亚胺键 COF**：模型未在硼酸酯、酰亚胺等其他键合类型上训练
- **仅预测成膜概率**：不预测膜的具体性能（厚度、结晶度、分离性能等）
- **需要有效 SMILES**：输入必须是合法且可解析的 SMILES 字符串
- **单体需含 >=2 个反应官能团**：单官能团单体无法形成 2D 网络
