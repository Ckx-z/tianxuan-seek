# 项目缺陷与不足系统性复盘

日期：2026-05-21

---

## 一、数据层：比模型架构更重要的问题

### 1.1 标签定义模糊 [已解决]
- ~~「成膜」在 954 篇文献中无统一标准~~——讨论后认为：文献若能成膜必定以膜的形式发表，标签策略有化学合理性
- 模型预测目标「醛-胺对在化学上能成膜」与筛选第一步（只保留醛+胺单体）一致

### 1.2 负样本不可信 [已解决]
- 理由同上：COF 领域发表规律支持标签策略。做不成的文章也要发，只是以粉末/结晶形式，y=0 标注合理
- 当前 33.3% 正样本比在实际化学空间中属合理

### 1.3 反应条件噪音 [待解决]
- 687 对训练样本来自不同文献，溶剂/温度/催化剂各异
- 同一对单体在溶剂 A 成膜、溶剂 B 不成的信息被压缩为一个标签
- 模型学到的「结构-成膜」关系混杂大量反应条件噪音

**解决方案讨论**：
- 方案一：CondPairPredictor 直接编码反应条件（代码已有，53维，需构建特征矩阵+训练）
- 方案二：条件鲁棒性评分 — GNN 编码器学结构成膜潜力，条件感知头学条件依赖，两个头共享编码器但梯度分离，推理时只用鲁棒性头输出 r(x)。需要多实例配对数据
- 方案一+三结合（先训练 CondPairPredictor + 推理时固定最优条件 + 后处理做溶剂/温度匹配度调整）

### 1.4 跨实验体系假配对 [严重 — 2026-05-21 新发现]

**问题**：一篇文章可能含多组独立实验（如 COF-Z1 和 COF-Z2），每组用不同的单体组合、溶剂和温度。当前解析逻辑假设一篇文章的所有单体和条件属于同一实验，把所有醛×所有胺做笛卡尔积配对。

**后果**：
- 一篇含 2 醛+2 胺分属两个实验的文章，笛卡尔积产生 4 对，实际实验过的可能仅 2 对
- 未实验过的配对被错误赋予了该文章的成膜标签（假阳性或假阴性）
- 不同实验体系的溶剂/温度被混淆，加剧 1.3 的条件噪音问题
- 当前 687 对训练样本中，未知比例的配对可能是这种跨体系假配对

**发现来源**：抽查 YAML 发现 reagent 字段含「用于COF-Z1」「用于COF-Z2」等分组描述，溶剂字段也区分了不同体系的溶剂。

**修复方向**：
1. LLM 提取层：识别文章中的多组实验，每组独立输出 reagent/solvent/temperature/film_crystallinity_fluorine
2. 后处理层：对已有 954 篇 YAML 按分组关键词拆分（如「COF-Z1」「COF-Z2」等）
3. 影响面评估：先统计全量 954 篇中多大比例含多组实验、影响多少训练对

## 二、模型层：GCN 的先天不足

### 2.1 边特征未被使用
- smiles_to_graph() 构建了 5 维边特征（单键/双键/三键/芳香键/共轭），但 GCNConv 只接收 node features + edge_index
- 芳香键 vs 单键在卷积中权重完全相同

### 2.2 均值聚合抹平邻域差异
- 醛基邻位是 Cl 还是 H，在均值聚合下差异被 1/|N(i)| 归一化消除
- 无法保留邻域规模信息——「苯环上有 1 个 Cl」vs「有 3 个 Cl」电子效应显然不同

### 2.3 感受野不足
- 3 层 GCN 感受野约 3 个化学键
- 联苯级共轭延伸需 4-5 层才能覆盖
- 更大的共轭体系（三联苯、四苯基卟啉）可能被截断感知

## 三、评估层：提升是否可靠

### 3.1 统计显著性未验证
- 0.654→0.731 的 +11.8% 提升，但 64 折 CV 的标准差未知
- 若 GNN ±0.03 和 XGBoost ±0.04 重叠，统计显著性是存疑
- 需要报告 64 折 PR-AUC 的标准差/置信区间

### 3.2 无独立测试集
- 商业单体测试集（研伸科技 121 页目录）有数据但从未正式评估
- 训练/验证来自同一批文献的随机分割（RepeatedStratifiedKFold）
- 模型可能学到文献的发表年份/课题组偏好等混杂信号

### 3.3 集成权重可能涉及数据泄露
- GNN 60% : XGB 40% 和分歧惩罚 Δ=0.10 是网格搜索确定
- 若网格搜索在全量数据（含验证集）上进行 → 数据泄露

## 四、化学层：相关性 ≠ 因果

### 4.1 IG 归因 ≠ 化学因果
- IG 显示 Cl 取代是最大正向驱动（+1.74）
- 这可能是数据中的相关：文献中恰好含氯单体多 + 成膜率高 ≠「氯导致成膜」
- 需要用对照实验（同一醛的不同卤素取代 vs 成膜率）来验证

### 4.2 反应机理完全缺失
- GNN 无亚胺键形成可逆性、席夫碱平衡、水分子脱除等显式建模
- 溶剂极性、酸催化浓度、温度对亚胺键可逆性影响——模型完全不可见
- CondPairPredictor 已编码但未训练

### 4.3 拓扑判定是硬规则而非学习
- C3+C2→六方、C2+C2→四方是全量硬编码
- C3+C2 实际也可形成四方拓扑（若 C3 只有两个位点参与反应）
- 模型不学习拓扑，只学习「在给定拓扑约束下是否成膜」

## 五、工程层：流水线隐性风险

### 5.1 LLM 提取错误会传播
- 若 LLM 将「4-aminobenzaldehyde」误分类为胺（实际同时含醛基+胺基），后续分析全错
- 954 篇 YAML 没有逐篇人工校验，准确率依赖抽检估计的 >85%
- 同一 LLM prompt 对全部文献：LLM 模型更新可能导致提取结果前后不一致

### 5.2 单体名称→SMILES 解析有 ~15% 失败率
- 三级降级后仍有一些复杂名称（多取代基、金属配合物）无法解析
- 这些单体被静默排除——可能恰好是最有趣的结构
- PubChem 缓存随版本更新可能产生不一致

### 5.3 模型权重与训练代码不同步
- ranking_weight=0 变更已提交到代码，但模型权重 (end_to_end_a.pt, 5/14) 是变更前训练
- 重跑筛选不改变结果——此缺陷待重训练验证

## 六、实用性问题

### 6.1 模型能不能指导实验
- Top 40 推荐是「文献中类似结构能成膜」而非「这对单体一定能成膜」
- 拿 Top 40 直接做实验，预期成功率可能不到 30%
- C3 单体（TAPB、Tp）好买，但 C2 特殊取代基（硼酸酯、二乙烯基）可能需要定制合成

### 6.2 数据量根本性瓶颈
- 687 对训练样本对深度学习偏少
- 33.3% 正样本比在实际化学空间中可能远高于真实比例
- 若有机会获取高通量实验数据（数百个不同单体对+统一条件测试），模型质量可能质的飞跃

### 6.3 特征-目标因果链仍过长
- GNN 虽然比 Morgan 指纹直接，但「单体结构→成膜」的因果链涉及太多中间变量（聚合动力学、结晶热力学、界面效应）
- 或许需要分阶段建模：结构→反应活性→聚合度→结晶性→成膜
