# Phase 5 训练 — 工作总结

## 模块总览

| 文件 | 职责 |
|------|------|
| `v3_loss.py` | Focal Loss + 条件 CE + 化学正则化 + 对称性正则化 |
| `v3_scheduler.py` | chem warm-up + cosine lr with linear warm-up |

## 5.1 v3_loss.py — 损失函数

### 损失公式

```
L_total = L_film (Focal alpha=0.75 gamma=2, x film_quality_weight)
        + 0.1 x sum(L_cond_i)  (5 条件 CE)
        + chem_lambda x L_chem  (3 条规则, warm-up)
        + 0.01 x L_sym  (交叉注意力对称性)
```

### 组件

| 组件 | 实现 | 说明 |
|------|------|------|
| FocalLoss | `FL = alpha_t x (1-pt)^gamma x CE` | alpha=0.75, gamma=2 |
| condition_losses | 5 个独立 CE，缺失 mask | 缺失样本 loss=0 |
| symmetry_loss | `||A_ald - A_amine^T||_F^2` | 均值 over heads |
| chem_penalty | 从 ViolationCache 读取，x chem_lambda | warm-up 控制 lambda |

### 设计决策

| 决策 | 原因 |
|------|------|
| 条件缺失不做特殊处理 | 5 个头独立投影，缺失率高的头自然梯度少 |
| film_quality 权重接受现状 | 57.7% unknown(1.0), 12% high(1.5), 5% low(0.5)，微弱信号比没有好 |
| 对称性正则化 lambda=0.01 | 弱约束，不主导训练 |

## 5.2 v3_scheduler.py — 调度器

### Chem warm-up

| 阶段 | epochs 比例 | lambda |
|------|------------|--------|
| warm-up | 0-50% | 0 |
| ramp | 50-80% | 线性 0 → 0.005 |
| hold | 80-100% | 0.005 |

### 学习率调度

- cosine annealing with linear warm-up (5 epochs)
- 初始 lr=0.001, weight_decay=0.0001
- AdamW optimizer

## 5.3 v3_trainer.py — 训练器

### 训练循环

```
for epoch in range(max_epochs):
    train_metrics = train_epoch()
    val_metrics = validate()
    if val_pr_auc > best: save checkpoint
    if no_improve >= patience: early stop
```

### 关键特性

- 梯度裁剪 (grad_clip=1.0)
- 早停 (patience=30)
- best_state 深拷贝保存

## 5.4 train_v3.py — 训练主脚本

### 数据流

```
v3_train.csv → PairDataset (预转换分子图 + 条件标签)
            → ViolationCache (预计算化学违反度)
            → 文献级 StratifiedKFold (5 fold x 3 repeat = 15 folds)
            → V3Trainer 训练
```

### 文献级 GroupKFold

```python
# 每篇文献：有一个正样本 → 文献=正
paper_labels = df.groupby('paper_id')['is_film'].max()
# 对文献做 StratifiedKFold，展开到实验组
```

### 自定义 Dataset + collate_fn

PairDataset 预转换所有 SMILES → PyG Data，避免每 epoch 重复 RDKit 计算。
collate_fn 处理变长分子图的 batch 拼接（边索引 offset）。

### 模型保存

CV 完成后，用最佳 fold 重新训练并保存最终模型。
