## Phase 1 各层工作

### 1.1 条件归并解析 (`condition_parser.py`)

**做了什么**：将 LLM 提取的 5 个文本条件字段标准化为分类标签。

| 字段 | 类别数 | 类别 |
|------|--------|------|
| synthesis_route | 5 | solvothermal / interfacial / mechanochemical / room-temperature / other |
| interface_type | 3 | liquid-solid / liquid-liquid / other |
| catalyst | 5 | acetic_acid / PTSA / TFA / Sc(OTf)3_Lewis / none_other |
| solvent | 7 | dioxane_mesitylene / DCB_BuOH / water_based / DMF_DMSO / acetonitrile / alcohol / other |
| temperature | 5 箱 | rt(<30) / low(30-80) / standard(80-130) / high(130-200) / unknown |

**关键设计决策**：
- 同义词映射：催化剂名称标准化（醋酸→acetic_acid、对甲苯磺酸→PTSA 等）
- 溶剂名称标准化：o-DCB→DCB、n-BuOH→BuOH 等，再按体系归类
- 温度数值提取：正则 `\d+\s*(°C|℃|K)`，取最高温（多步骤时最苛刻条件）
- 同文献补充 (`fill_from_peers`)：缺失的 temperature/interface_type 从同文献其他实验组众数补充
- 非反应温度过滤：排除含「负载/熔融/干燥/测试/退火/drying/impregnation/annealing」等后处理关键词的温度值

**局限性及缓解**：

| 局限 | 严重度 | 缓解 |
|------|--------|------|
| 温度数值提取不准（LLM 可能提取了后处理温度而非反应温度） | 中 | `is_reaction_temperature()` 过滤非反应温度关键词；同文献众数补充 |
| interface_type 缺失率高达 53% | 高 | 同文献众数补充；ConditionHead 使用 missing_embedding 区分「缺失」与「other」 |
| solvent other 占 32%/25%，类别混合 | 低 | other 是合理的——目的是让模型学习「什么结构用什么溶剂」，而非精确分类 |
| 边界模糊（80°C 算 low 还是 standard） | 低 | 分箱边界来自 COF 领域经验，边界样本的误分类影响有限 |
| LLM 标签噪声（催化剂/溶剂名称可能拼写错误） | 中 | 同义词映射覆盖常见变体；模糊匹配兜底 |

### 1.2 单体过滤扩展 (`monomer.py`)

**做了什么**：新增 3 个检测函数，排除含金属单体和混合键体系。

#### `has_metal_smiles(smiles)` — SMILES 级金属检测

- 字符串预检：`[X]` 方括号标记的非有机原子
- RDKit 原子序数：> 18 且不在有机白名单 `{Se, Br, Te, I}` → 判定为金属
- 实际检测结果：SMILES 可解析的 943 对中，0 个含金属（LLM 提取阶段已过滤）

#### `has_metal_name(name)` — 名称级金属检测

两层匹配：
1. **骨架/配体关键词**：porphyrin/卟啉、phthalocyanine/酞菁、salen/salophen、TAPP、corrole/咔咯、MOF、配合物/络合物、bpy/bipyridine/phenanthroline/terpyridine、冠醚
2. **金属元素符号**（词边界正则 `\b`）：Fe/Co/Ni/Cu/Zn/Mn/Ru/Rh/Pd/Pt/Ir/Os/Re/Cr/Mo/W/V/Ti/Zr/Hf/Ag/Au/Cd/Hg/Al/Ga/In/Sn/Pb/Sb/Bi/Mg/Ca/Sr/Ba/La/Ce/Eu/Tb

**修复的问题**：`In`（铟）在 `diamine` 中误匹配 → 改用 `\bIn\b` 词边界

#### `is_imine_only(chemistry_type)` — 纯亚胺体系判定

黑名单优先于白名单：
1. 先查黑名单：hydrazone/imide/boronate/olefin/triazine/phenazine/azine/mixed/hybrid/post-modification/PSM/thiazole/keto-enamine/reduced/polymer 等 → 排除
2. 再查白名单：imine/Schiff base/亚胺/席夫碱 → 通过
3. 都不匹配 → 排除（保守策略）

**过滤效果**：817 篇文献中 601 篇 (73.6%) 通过 imine 判定

**局限性及缓解**：

| 局限 | 严重度 | 缓解 |
|------|--------|------|
| SMILES 金属检测漏掉稀有金属（如镧系配合物） | 低 | 名称关键词覆盖 La/Ce/Eu/Tb；稀有金属在 COF 中极少见 |
| 名称关键词遗漏边缘 case | 低 | 扩展了 corrole/咔咯/bpy/phenanthroline/terpyridine/冠醚 |
| chemistry_type 依赖 LLM 提取质量 | 中 | 黑名单覆盖了所有已知的非亚胺键类型；未标注的文献被保守排除 |
| TAPP free-base 卟啉被排除（无金属但骨架是金属配体） | 中 | 刻意排除——free-base 卟啉虽无金属但结构行为与金属配位卟啉相似，且成膜行为不同 |
| 硬编码关键词维护成本 | 低 | 后续移交至配置文件 `config/monomer_filter.yaml` |

## v3 结构化信息分层使用策略

### 核心原则

**CSV 是训练快照，YAML 是真相源。** `v3_train.csv` 只包含训练需要的列，保留 `paper_id` + `group_id` 可随时回溯 YAML 原文。

### 三层策略

```
┌─────────────────────────────────────────────────────────────┐
│ v3 核心 (Phase 1-7, 现在就用)                                │
│ ├── GNN 输入: aldehyde_smiles + amine_smiles                │
│ ├── 标签: is_film (0/1)                                     │
│ ├── 样本权重: film_quality → quality_weight (1.5/1.0/0.5)   │
│ ├── 条件辅助任务: 5 条件字段 → ConditionHead                 │
│ └── 特征标记: has_F, has_N_heterocycle                       │
├─────────────────────────────────────────────────────────────┤
│ v3.1 增强 (下一轮)                                           │
│ ├── 对比学习: design_rationale + comparison → 同文献对照组   │
│ ├── 多任务: film_description → 结晶性/比表面积预测           │
│ └── 文本嵌入: from_text → 小型 LM 编码实验描述               │
├─────────────────────────────────────────────────────────────┤
│ v3.2 精炼 (后续)                                             │
│ ├── 置信度校准: confidence → 标签噪声估计/样本降权           │
│ ├── 实验细节: post_treatment, atmosphere, additives         │
│ └── 回溯查询: 预测失败时回 YAML 原文分析原因                 │
└─────────────────────────────────────────────────────────────┘
```

### 闲置字段清单（v3 不用但保留在 YAML 中）

| 字段 | 潜在用途 | 优先级 |
|------|----------|--------|
| `design_rationale` | 对比学习——同文献对照组逻辑 | v3.1 |
| `comparison` | 实验组间关系 | v3.1 |
| `film_description` | 多任务——结晶性/比表面积/形貌 | v3.1 |
| `film_type` | 细化负样本类型 (powder/gel/amorphous) | v3.1 |
| `confidence` + `confidence_note` | 标签噪声估计 | v3.2 |
| `post_treatment` | 后处理对成膜的影响 | v3.2 |
| `atmosphere` | 气氛条件特征 | v3.2 |
| `additives` | 添加剂特征 | v3.2 |
| `monomer_concentration` | 浓度特征 | v3.2 |
| `duration` | 反应时间特征 | v3.2 |
| `catalyst_amount` | 催化剂用量特征 | v3.2 |
| `substrate` | 基底特征 | v3.2 |
| `from_text` / `from_figure` | 文本嵌入 | v3.2 |
| `xrd_peaks` / `afm_rms` / `bet_surface_area` 等 | 多任务预测目标 | v3.1 |
| `char_methods` / `char_key_findings` | 表征质量评估 | v3.2 |
| `stoichiometry` | 反应计量比特征 | v3.1 |
