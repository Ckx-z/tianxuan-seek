# 2026-05-26 v3 实现计划

## 讨论背景

2026-05-25 完成了 v3 模型升级的全部 12 个设计议题讨论，每个方案都附带局限性和缓解措施。今日（05-26）进行实现规划。

## 昨日决策回顾（12 个方案 + 局限性）

### 1. 模型目标（§1）
- 纯 GNN 二分类，film_quality 作为样本权重（high=1.5, medium=1.0, low=0.5）
- 5 局限：二分类掩盖连续谱、film_quality LLM 标注质量存疑、权重无理论依据、辅助任务噪声、丢弃失败模式

### 2. 条件编码（§2）
- 辅助任务 ConditionHead：synthesis_route(5类)/interface_type(3类)/catalyst(5类)/solvent(7类)/temperature(5箱)
- L = L_film + 0.1 × ΣL_cond，缺失用 missing_embedding
- 5 局限：主/辅梯度冲突、LLM 标签噪声、缺失率高、条件共线性、temperature 回归改分类

### 3. 负样本策略（§3）
- 仅 imine，排除 hydrazone/imide + 金属单体 + 非COF/纯计算
- 粉末 = 不成膜
- 过滤后 1448 组（正 430 / 负 1018，29.7%）
- 3 局限：假阴性、发表偏置、不平衡

### 4. Benchmark（§4）
- 保留商业单体独立测试，仅最终评估

### 5. 3D 构象（§5）
- 训练推理都生成，RDKit EmbedMultipleConfs，λ_3D=0.001
- 4 局限：气相≠反应构象、多构象选择、大分子失败、一致地错误

### 6. Warm-up（§6，合并至 §10）
- 前 50% λ=0 → 50-80% 线性增 → 后 20% 恒定

### 7. 池化 B+C+D（§7）
- B: 位置编码 + C: 交叉注意力 + D: 3D 距离偏置
- 7 局限：2D≠3D 距离、参考点敏感、构象真实性、多构象、过拟合、BC 重叠

### 8. 交叉注意力 + 交互公式（§8）
- h = [ea' || eb' || ea'⊙eb' || e_pair] → MLP → 1
- 去掉 ea-eb、bilinear、extra_26d
- 9 局限：维度对齐、二阶交互、池化稀释、空间约束、计算量、注意力偏置、对称性、归纳偏置

### 9. 配对策略（§9）
- 六层过滤：拓扑(硬) → 对称性 → LogP → 刚性 → 共轭 → 位阻(软降权)
- 7 局限：LogP≠真实溶剂、对称性误判、无跨层交互、缺反应活性、缺氢键检测、阈值经验、叠加过度

### 10. 化学正则化（§10）
- 5 条连续可微规则：苯环必需/官能团对称/C2对位/芳香复杂度/取代基限制
- 只罚假阳性，warm-up 调度
- 6 局限：阈值经验、取代基体积、C2多苯环、只罚不奖、数据冲突、对称性检测

### 11. GNN 架构（§11）
- GIN+GINE ×5 + JK-Net + 残差 + LayerNorm
- Siamese 共享编码器 + 单体角色标记
- ~95 万参数
- 5 局限：ε退化、过平滑、边特征未入注意力、角色差异、缺分子间键偏置

### 12. 条件归并（§12）
- 5 字段正则解析 → 分类/分箱
- 7 局限：温度不准、溶剂比例丢失、催化剂浓度丢失、边界模糊、缺失率高、LLM不一致、格式漂移

## v3 实现计划

### 总体框架（7 个 Phase）

```
Phase 0: 配置前置 — model_v3.yaml 定义所有超参数
    └── 0.1 model_v3.yaml           # encoder/heads/attention/training 配置源

Phase 1: 数据层 — 条件解析 + 单体过滤 + 数据集构建
    ├── 1.1 condition_parser.py    # 5 条件归并解析
    ├── 1.2 monomer.py 扩展         # 金属检测、imine-only
    └── 1.3 build_v3_dataset.py    # 两库合并 + 过滤 → 训练集

Phase 2: GNN 编码器 — GIN+GINE + 交叉注意力 + 预测头 (3D 延后)
    ├── 2.1 featurizer.py          # 原子 37 维 + 边 5 维
    ├── 2.2 encoder.py             # GIN+GINE x5 + JK-Net
    ├── 2.3 conformer.py           # [延后] RDKit 3D 构象 — 等 Phase 5 训练稳定后加
    ├── 2.4 attention.py           # Cross-Graph Attention
    ├── 2.5 pooling.py             # Attention Pooling
    ├── 2.6 heads.py               # FilmHead + ConditionHead
    └── 2.7 model.py               # V3Model 组装

Phase 3: [已合并至 Phase 6] 配对策略不在训练路径上，训练集是文献已有配对

Phase 4: 化学正则化 — 3 条化学硬事实 + warm-up
    ├── 4.1 chem_penalty.py          # 纯 RDKit 模块，不依赖 GNN；输入 SMILES → 输出违反度标量
    └── 4.2 warm-up scheduler        # 移至 v3_scheduler.py

    ### 3 条化学正则化规则 (仅保留几乎无例外的化学硬事实)

      1. 苯环必需:     (1 - min(n_phenyl, 1)) × prob    — COF 成膜必须有芳环
      2. 官能团对称:    max(0, 0.5 - fg_symmetry) × prob — C2/C3 官能团必须对称
      3. C2 对位:       is_c2 × (1 - is_para) × prob     — C2 必须对位

    已删除 (交给 GNN 自己学):
      - 取代基限制、溶解性匹配、刚性匹配、共轭匹配、位阻匹配、芳香复杂度

    设计原则:
      - 只罚假阳性，不罚假阴性
      - 惩罚 ∝ 违反程度 × 预测概率，梯度通过 prob 回传
      - λ_chem=0.005，warm-up 调度
      - 模型应自己学到化学兼容性，规则只提供最基础的化学常识

Phase 5: 训练 — 损失函数 + 训练循环 + 评估
    ├── 5.1 v3_loss.py             # Focal Loss + 多任务 + 化学正则化
    ├── 5.2 v3_scheduler.py        # warm-up 调度 + 学习率调度
    ├── 5.3 v3_trainer.py          # Trainer 类 (train/validate/save)
    ├── 5.4 train_v3.py            # 训练循环主脚本 (精简)
    └── 5.5 eval_v3.py             # Benchmark 评估

Phase 6: 筛选 — 拓扑硬约束 + GNN 推理 + Top 40
    ├── 6.1 pairing.py             # 仅拓扑硬约束 (C4+C4 排除)
    └── 6.2 screen_v3.py           # 全量配对 + GNN 推理 + 概率排序 + Top 40

    设计哲学: 信任模型。3.2M 参数 GNN + 交叉注意力 + 化学正则化弱信号，
    模型应自己学到化学兼容性。规则只保留拓扑硬约束（化学事实，非经验规则）。
    无软约束 tiebreaker — GNN 概率直接排序。
```

### 损失函数

```
L_total = L_film (Focal α=0.75 γ=2, ×film_quality_weight)
        + 0.1 × (L_route + L_interface + L_catalyst + L_solvent + L_temp)
        + 0.001 × L_3D
        + λ_chem(t) × L_chem  (warm-up 调度)
        + λ_sym × ||A_ald - A_amine^T||
```

### 评估策略

- 内部验证：RepeatedStratifiedKFold (8×8) + 文献级 GroupKFold
- 外部泛化：Benchmark 商业单体独立测试
- 消融实验：逐条去掉条件/3D/化学正则化/交叉注意力
- 基线对比：v1 XGBoost (0.654) vs v1 GNN (0.731) vs v3 GNN

### 成功标准

- 训练集过滤正确（仅 imine + 排金属 + SMILES 完整）
- GIN+GINE 参数量 ~95 万
- CV PR-AUC > 0.75
- Benchmark PR-AUC > 0.65

### 实现原则

**每个 Phase 的每一部分实现前，先讨论其局限性和后果，确认后再动手。**

## 调整记录

### 2026-05-27 调整

1. **Phase 2.3 conformer 延后**：λ_3D=0.001 权重极低，局限多。先跑纯 2D 基线，等 Phase 5 训练稳定后再加。
2. **Phase 4.1 明确依赖**：化学正则化需要原子级嵌入，依赖 Phase 2.2 (encoder) + Phase 2.5 (pooling) 完成后才实现。
3. **Phase 5 拆分**：train_v3.py 拆为 v3_loss.py + v3_scheduler.py + v3_trainer.py + train_v3.py，避免单文件过长。
4. **Phase 7 model_v3.yaml 前置至 Phase 0**：配置在 Phase 2 开始前定义，所有模块从配置读取参数。
5. **Phase 3 合并至 Phase 6**：配对策略不在训练路径上，训练集是文献已有配对不需要过滤。六层过滤在 Phase 6 筛选时使用，修正了刚性降权方向（仅降权全柔+全柔）、共轭改为连续芳香度差异、位阻改为反应位点邻域原子数。
6. **Phase 4 化学正则化精简至 3 条**：仅保留几乎无例外的化学硬事实（苯环必需/官能团对称/C2对位）。删掉取代基限制、溶解性、刚性、共轭、位阻——交给 GNN 自己学。Phase 6 筛选也只保留拓扑硬约束，完全信任模型。
