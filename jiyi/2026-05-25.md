# 2026-05-25 v2 模型升级讨论

## 讨论背景

v2 数据已就绪（894 篇文献，2644 实验组去重后，SMILES 覆盖率 74.2%）。v1/Phase 6 GNN 方案存在根本性缺陷，需要系统性地重新设计模型目标和架构。

## v1 的核心问题回顾

### 数据层面
1. **标签粒度粗糙**：文献级标签（一篇文献一个成膜/不成膜），但一篇文献含多组实验
2. **标签定义与成膜原理脱节**：二分类掩盖了膜质量的连续谱（无定形沉淀 → 不连续沉积 → 连续多晶膜 → 高质量单晶膜）
3. **负样本定义混乱**：混入了非亚胺键体系、条件未优化的假负样本
4. **反应条件完全忽略**：21 字段中的溶剂/温度/催化剂等未进入特征空间

### GNN 架构层面
1. **边特征被丢弃**：GCNConv 不支持 edge_attr，5 维键特征（单键/双键/三键/芳香/共轭）从未被使用
2. **全局平均池化丢失官能团位置信息**：无法区分对位/间位/邻位
3. **Siamese 独立编码后交互太晚**：位阻匹配、溶解性匹配等配对级属性在独立编码阶段丢失
4. **3 层 GCN 感受野不足**：大分子（卟啉、酞菁）的远端取代基效应无法传递
5. **680 样本训练 158 万参数**：严重过拟合风险

### 特征层面
1. **Morgan 指纹与成膜机理因果链断裂**：无法表达单体刚性、π-π 堆积能力、动态共价键可逆性
2. **26 维机理描述符与 GNN 嵌入信息冗余**：手工特征与自动学习矛盾

### 训练策略层面
1. **化学惩罚项梯度断裂**：阶跃函数 `(probs > 0.5).float()` 在阈值处不连续
2. **排序损失已关闭**：苯>炔化学先验未生效
3. **Ensemble 权重 6:4 缺乏理论依据**

### 筛选管线层面
1. **暴力笛卡尔积配对**：不考虑化学兼容性（溶解性、位阻、反应活性匹配）
2. **多层后处理使归因困难**：9 层逻辑叠加，无法解释「为什么排第一」

## 今日讨论结论

### 1. 模型目标重新定义
- **放弃 XGBoost**，由 GNN 单独完成任务
- **主任务保持二分类**（成膜/不成膜），不升级为膜质量预测
- **film_quality 作为样本权重**（非预测目标）：
  - high → 权重 1.5，medium → 权重 1.0，low → 权重 0.5
  - 高质量膜样本在 loss 中贡献更大，模型倾向于推荐高质量膜组合
  - 缺失 film_quality 的样本默认权重 1.0

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| 二分类掩盖膜质量连续谱（勉强成膜 vs 完美单晶都标为 1） | 中 | film_quality 样本权重部分缓解 |
| film_quality 是 LLM 从文献描述提取，非实验测量，不同文献标准不一致 | 高 | 实现前统计分布，和 XRD/AFM 等客观表征交叉验证 |
| 样本权重 1.5/1.0/0.5 无理论依据，差距可能过大导致忽略 low 样本 | 中 | 消融实验调优，考虑更温和的 1.3/1.0/0.7 |
| 辅助任务条件标签噪声（LLM 提取不准）可能误导 GNN 编码器 | 中 | 先统计 5 条件标注质量和分布，必要时降 λ_cond |
| 丢弃失败模式信息（沉淀/不连续/剥离），模型只知道失败不知道原因 | 低 | 未来多类别扩展，当前阶段可接受 |

### 2. 条件特征编码方案
- **主任务（BilinearHead）**：只看单体结构，预测成膜潜力。推理时不依赖条件
- **辅助任务（ConditionHead）**：输入分子嵌入，预测 5 个条件标签
  - `synthesis_route`（归并到 ~7 类）
  - `interface_type`（归并到 ~5 类）
  - `catalyst`（归并到 ~6 类）
  - `temperature`（回归，°C）
  - `solvent`（归并到 ~8 类）
- **损失函数**：`L = L_film + λ_cond * (L_route + L_interface + L_catalyst + L_solvent + L_temp)`
- **λ_cond** 建议从 0.1 起步
- **缺失值**：用可学习的 `missing_embedding` 补全，缺失样本不参与该维度 loss
- **类别编码**：归并后用 Embedding（每类 8-16 维），数值做 StandardScaler
- **条件特征位置**：不进入 GNN 编码器，在 BilinearHead 输入层与分子嵌入拼接

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| 主/辅任务梯度冲突——主任务要嵌入对条件不敏感，辅助任务要嵌入对条件敏感 | 高 | PCGrad 梯度手术（冲突时投影到正交方向）或独立 ConditionEncoder |
| LLM 提取的条件标签噪声（solvothermal/hydrothermal 混淆、温度提取错误等） | 高 | 实现前对每个条件字段做分布统计和异常值清洗 |
| 缺失率高的条件训练不充分（如 80% 样本缺 catalyst，辅助任务只有 20% 有效） | 中 | 先统计缺失率，> 50% 的条件降权或暂时去掉 |
| 条件间共线性（synthesis_route ↔ interface_type 高度相关） | 中 | 统计条件间互信息，高共线合并或去掉一个 |
| temperature 做回归不稳定（文献中温度常是范围/模糊描述/缺失） | 中 | 改为分类（分箱 5-6 区间），而非回归 |

### 3. 负样本策略（已确认）

**保留的化学体系**：仅 imine（亚胺键），排除 hydrazone、imide（样本极少且成膜机理不同）

**排除规则（全部满足才保留）**：
1. chemistry_type = imine
2. aldehyde_smiles 非空 AND amine_smiles 非空
3. is_film IS NOT NULL
4. 排除含金属单体（SMILES 含 [Metal] 或名称含 porphyrin/phthalocyanine/salen/TAPP/Pc）
5. 排除非 COF 体系（SOF、supramolecular 等）
6. 排除纯计算/综述/非实验文献

**负样本定义**：粉末 = 不成膜。文献中产物描述为「粉末/powder」即视为未形成连续膜，作为负样本。这符合 COF 成膜的基本事实——粉末状产物无法形成连续二维薄膜。

**过滤后实际**：1448 组（正 430 / 负 1018，正样本率 29.7%），去重后数据

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| 负样本含「条件不当」假阴性——is_film=0 可能是因为条件没优化而非结构不行 | 高 | 辅助任务间接缓解（预测最优条件下可能成膜），无法根除 |
| 文献发表偏置——真正「结构上不可能成膜」的负样本很少被发表 | 高 | 数据源根本限制，benchmark 独立测试检测泛化差距 |
| 正负样本比例 29.7%，PR-AUC 对不平衡敏感 | 中 | Focal Loss + 动态 α = 1 - pos_rate |

### 4. Benchmark 独立测试保留
- **保留 benchmark_pairs**（商业单体目录），但不参与训练和超参调优，只在最终评估时跑一次
- 作用：检测**分布外泛化**能力——CV 验证同分布，benchmark 验证全新化学骨架
- 如果 CV PR-AUC 高但 benchmark 低 → 模型过拟合文献偏置，不可部署

### 5. 3D 构象生成策略
- **训练和推理都生成 3D 构象**，保持输入一致性，避免 train-inference gap
- RDKit `EmbedMultipleConfs` ~0.1s/分子，筛选集 ~20,000 对 → 总计约 1 小时，可接受
- 3D 构象作为辅助输入（非主输入），提供空间位阻、构象柔性等信息

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| RDKit 气相构象 ≠ 溶剂界面真实反应构象，系统性偏离无法避免 | 高 | λ_3D 设很小（0.001 量级），仅做弱辅助信号 |
| 多构象选择困难——柔性分子有多个旋转异构体，取哪个？ | 中 | 取最低能构象 + 微小随机扰动做数据增强 |
| 大分子构象生成失败（卟啉/酞菁/笼状分子 EmbedMultipleConfs 可能失败） | 中 | 失败时退化为 2D 特征，不强制 |
| 训练-推理一致但「一致地错误」——若 RDKit 构象系统性偏离真实构象 | 中 | λ_3D 足够小，不主导预测，降低错误影响 |

### 6. Warm-up 正则化策略（已确认，已合并至 §10）
- 选择 **Warm-up** 而非可学习权重
- 理由：化学规则是领域先验，不应从数据中学习；warm-up 让数据先说话，规则后校正边界 case
- 具体方案：前 50% epochs λ_chem=0 → 50%-80% 线性增加到预设值 → 最后 20% 保持恒定
- 详见 §10 化学先验正则化

### 7. 池化策略升级 — 解决位置信息丢失（已确认）

**问题**：global_mean_pool 把所有原子向量取平均，抹掉官能团位置信息（对位/间位/邻位无法区分）

**方案 B + C + D 组合**：
- **方案 B（位置感知特征）**：在原子特征中显式加入官能团相对位置编码（醛基/胺基到分子几何中心的距离、角度），不改变架构
- **方案 C（交叉图注意力）**：不做全局池化，保留原子级嵌入矩阵，用 Cross-Graph Attention 让醛的每个原子和胺的每个原子直接交互，模型学习「醛的哪个位点和胺的哪个位点反应」
- **方案 D（3D 构象辅助）**：RDKit 低能构象提供原子 3D 坐标，在注意力中融入距离感知偏置

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| 2D 拓扑距离 ≠ 3D 空间距离（B 的位置编码基于分子图最短路径） | 中 | 优先用 3D 距离替代图距离做位置编码 |
| 参考点选择敏感（B 用分子几何中心，柔性分子中心随构象漂移） | 中 | 用官能团位置而非分子中心做参考点 |
| RDKit 气相构象 ≠ 溶剂界面真实反应构象（D） | 高 | λ_3D 设很小（0.001 量级），仅做弱辅助信号 |
| 多构象选择困难（D，柔性分子有多个旋转异构体） | 中 | 取最低能构象 + 微小随机扰动做数据增强 |
| 大分子构象生成失败（D，卟啉/酞菁/笼状分子） | 中 | 失败时退化为 2D 特征，不强制 |
| B+C+D 叠加信息过载，~3000 样本可能过拟合 | 中 | 位置编码和 3D 坐标维度控制在 5-8 维 |
| B 和 C 信息重叠（位置编码 vs 注意力学到原子关系） | 低 | 消融实验验证增量收益，必要时去掉 B |

### 8. Siamese 独立编码 → 交叉注意力（已确认）

**问题**：v1 两个单体独立编码，只在最后 BilinearHead 交互，位阻匹配、溶解性匹配、反应活性匹配等配对级属性在独立编码阶段丢失

**方案**：Cross-Graph Attention 在原子级别交互
- 醛原子查询 × 胺原子键 → 醛的每个原子关注胺的所有原子（反之亦然）
- 醛基碳自动关注胺基氮，模型学到化学合理的配对模式
- 交叉注意力输出做池化 → 配对级嵌入 → 预测头

**交互公式精简**：
```
h = [ea' || eb' || ea'⊙eb' || e_pair]  # 4×256 = 1024 维
output = MLP(h) → 1
```
- `ea'`：醛本身的成膜倾向（交叉注意力后）
- `eb'`：胺本身的成膜倾向（交叉注意力后）
- `ea'⊙eb'`：醛胺特征共现/协同匹配（核心交互）
- `e_pair`：交叉注意力池化后的原子级配对信息
- 去掉 `ea - eb`（冗余，MLP 可学到差异）、`bilinear`（和哈达玛积高度相关）、`extra_26d`（已废弃）

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| 哈达玛积假设醛胺在同一维度空间对齐，若 GNN 未学到对齐则是噪声 | 中 | 交叉注意力促进 ea'/eb' 互相感知，推动维度对齐 |
| 哈达玛积只捕获二阶交互，化学匹配可能是高阶的 | 低 | MLP 2-3 层深度补偿，学习高阶特征组合 |
| e_pair 池化稀释反应位点信号（醛基 C、胺基 N 只是少数原子） | 中 | 用 attention pooling 替代 mean pooling，自动聚焦反应位点 |
| 缺少空间可达性显式约束——醛基被大位阻包裹+胺基也被包裹，模型可能误判 | 高 | 3D 构象距离信息 + 化学正则化（后续设计） |
| 交叉注意力 O(N_ald × N_amine) 计算量，大分子时注意力矩阵膨胀 | 低 | 实际分子 20-40 重原子，推理一次性前向传播，可接受 |
| 注意力可能聚焦非反应位点（苯环互相关注而非醛基 C→胺基 N） | 高 | 方案 B 在原子特征中显式标记反应位点类型，引导注意力 |
| 缺少 3D 空间距离约束——远处原子对也被全连接关注 | 高 | 方案 D 在注意力中融入距离偏置，超过阈值压制权重 |
| 双向注意力不对称（A_ald ≠ A_amine^T），需额外学习对称性 | 中 | 对称性正则化辅助 loss：\|\|A_ald - A_amine^T\|\| |
| 缺乏化学键形成归纳偏置——模型不知道醛基 C+胺基 N→C=N 键 | 中 | 方案 B 反应位点类型编码，提供先验知识 |

### 9. 配对策略升级（已确认）

**从暴力笛卡尔积 → 六层化学兼容性过滤**：

| 层级 | 约束 | 类型 | 规则 |
|------|------|------|------|
| 1. 拓扑 | 官能团数量匹配 | 硬约束 | C2+C2, C3+C2, C3+C3, C4+C2 保留；C4+C4 排除（不可控交联） |
| 2. 对称性 | 单体对称性匹配 | 软约束 | RDKit 原子等价类判断点群近似；Cs+高对称 → 降权 |
| 3. 溶解性 | LogP 差异 | 软约束 | \|LogP_ald - LogP_amine\| ≤ 4 保留；> 4 降权 |
| 4. 刚性 | 可旋转键数差异 | 软约束 | 全刚性+全柔性 → 降权 |
| 5. 共轭 | 芳香度差异 | 软约束 | 全芳香+全脂肪 → 降权（共轭断裂影响 π-π 堆积） |
| 6. 位阻 | 反应位点可及性 | 软约束 | 双侧大位阻 → 降权（SAS-like 分数） |

**降权方式**：软约束不硬排除，乘以兼容性系数（0.7-0.9），模型仍可见但有化学风险标记。设最低系数下限 0.5，防止多层叠加过度降权。

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| LogP 是辛醇-水分配系数，≠ COF 真实溶剂体系（二氧六环/均三甲苯/DMF）溶解性 | 中 | 最实用的近似；后续可用多溶剂 LogS 或溶剂极性参数 ET30 |
| 对称性判断对柔性分子不准（侧链旋转导致 C3→Cs 误判） | 中 | 原子等价类 + 官能团几何排列联合判断 |
| 六层顺序执行无跨层交互（LogP 差+位阻小可能补偿，但被独立判断） | 中 | 系数相乘允许一定补偿，不硬排除 |
| 缺少反应活性匹配（缺电子醛 vs 富电子胺反应更快） | 中 | Hammett 常数或 RDKit 原子电荷评估，实现复杂 |
| 缺少氢键供体/受体干扰检测（-COOH/-OH/-NH₂ 竞争亚胺键氢键） | 中 | 用 RDKit HBD/HBA 计数，含强氢键位点降权 |
| 阈值全凭经验（LogP 差 4、可旋转键差异、芳香度差异） | 中 | 实现后统计 v2 正样本分布，数据驱动调优阈值 |
| 软约束叠加过度降权（触发三层 = 0.8³ = 0.51，四层 = 0.41） | 低 | 设最低系数下限 0.5，低于下限不再叠加 |

### 10. 化学先验正则化（已确认）

**v1 问题**：`(probs > 0.5).float()` 阶跃函数导致梯度断裂，化学惩罚项对训练无梯度信号

**v3 方案**：5 条硬规则 → 连续可微软正则化，所有项可反向传播

| 规则 | 可微形式 | 逻辑 |
|------|---------|------|
| 苯环必需 | `(1 - min(n_phenyl, 1)) × prob` | 无芳香环但预测成膜 → 罚 |
| 官能团对称 | `max(0, 0.5 - fg_symmetry) × prob` | 不对称但预测成膜 → 罚 |
| C2 对位 | `is_c2 × (1 - is_para) × prob` | C2 非对位但预测成膜 → 罚 |
| 芳香体系复杂度 | `sigmoid((linear_chain - 3)/T) × prob + max(0, n_aromatic - 5) × prob` | 直链苯 > 3 或芳环 > 5 → 罚（合并原规则 4+6） |
| 取代基限制 | `max(0, ortho_volume - V_thresh) × prob / n_fg` | 邻位拥挤但预测成膜 → 罚（用范德华体积加权） |

**设计原则**：
- 只罚「假阳性」（违反规则但预测成膜），不罚「假阴性」
- 惩罚 ∝ 违反程度 × 预测概率
- 用 max(0, x)、min(x, 1)、sigmoid 等平滑函数，不用阶跃
- Warm-up：前 50% epochs λ=0, 50%-80% 线性增加, 最后 20% 恒定
- λ_i 在 0.001-0.01 量级

**已去掉的 v1 规则**：
- C3 bonus：样本中成膜大部分是 C3+C2，数据分布自然结果
- 含炔降权：已关闭
- N 杂环 bonus：模型有能力从数据中学到
- Ensemble 分歧惩罚：纯 GNN 不适用

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| 阈值全凭经验（0.5 对称性、3 直链苯、5 芳环） | 中 | 实现后逐条消融实验，按 PR-AUC 变化调优 |
| 取代基只看数量不看体积（F vs 叔丁基位阻不同） | 中 | 用 RDKit Taft 立体参数或范德华体积加权替代简单计数 |
| C2 对位需处理多苯环单体（联苯二甲醛非经典 1,4-取代） | 低 | 检测两官能团几何矢量是否共线，而非简单 1,4-取代判断 |
| 只罚不奖（无正向奖励对称/对位好的单体） | 低 | 正样本 loss 已有正向信号，可接受 |
| 规则可能与训练数据冲突（数据中存在违反规则但成膜的案例） | 低 | Warm-up 减轻 + 实现前统计 v2 数据中每条规则的违反率 |
| 官能团对称性检测依赖 RDKit 原子等价类，构象柔性可能误判 | 低 | 阈值 0.5 留有容错空间 |

### 11. GNN 架构升级（已确认）

**选型**：GIN + 边特征增强（GINE 风格），表达能力 = WL 测试理论上界

**架构概要**：
```
输入: 原子特征(29维) + 位置编码(5维) + 反应位点标记(2维) + 角色标记(1维) = 37维
   ↓
编码器: Linear(37→64) → GIN+EdgeGate ×5 → 256维原子嵌入
   ↓  (JK-Net: 每层输出拼接，保留多尺度信息)
交互层: 交叉注意力 + 3D距离偏置 + 反应位点对编码
   ↓
池化: Attention Pooling → ea', eb', e_pair
   ↓
预测头: [ea' || eb' || ea'⊙eb' || e_pair] → MLP(1024→128→64→1) → 成膜概率
   ↓
辅助头: ConditionHead(ea', eb') → 5条件预测
   ↓
正则化: L_chem(5条化学规则) + 对称性正则化 ||A_ald - A_amine^T||
```

**关键设计**：
- 边特征用 GINE 加法式融入（经 MLP 映射后加到邻居嵌入），不用门控调制
- 5 层 GIN + JK-Net 拼接保留多尺度信息，防止小分子过平滑
- Siamese 共享编码器 + 单体角色标记（醛/胺），输入特征区分角色
- 交叉注意力中融入原子局部键环境摘要 + 反应位点对显式编码
- 参数量 ~95 万，比 v1 减少 ~40%

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| GIN ε 参数可能在小数据集退化（~3200 样本学不到有意义区分度） | 中 | 固定 ε=0，用 GINE 标准加法式边特征融入 |
| 5-6 层在小分子上过平滑（对苯二甲醛 8 重原子，5 层后信息传遍全图） | 中 | JK-Net 拼接每层输出，保留多尺度信息；可探索动态深度 |
| 边特征未融入交叉注意力——醛原子 i 关注胺原子 j 时不知道各自键环境 | 中 | 原子局部键环境摘要（入射边特征 mean pooling）拼入嵌入 |
| Siamese 共享权重忽略醛/胺化学角色差异（亲电 vs 亲核） | 中 | 单体角色标记（1 维）拼入原子特征，让共享编码器感知角色 |
| 缺少分子间化学键形成归纳偏置（C=N 键不在任何单体图结构中） | 中 | 交叉注意力中显式编码反应位点对的距离和类型作为注意力偏置 |

### 12. 5 个条件归并映射 + 文本正则解析（已确认）

**数据现状**（数据库 1，1448 组 imine）：

| 字段 | 填充率 | 格式 |
|------|--------|------|
| synthesis_route | 104% | 71% solvothermal，12% interfacial |
| interface_type | 70% | 74% liquid-solid，21% liquid-liquid |
| catalyst | 82% | 64% acetic acid，其余分散 |
| solvent | 101% | 最多样化（dioxane/mesitylene/DCB/BuOH/water...） |
| temperature | 98% | 77% 含数字，33% 室温 |

**归并映射**：

| 字段 | 类别数 | 映射规则 |
|------|--------|---------|
| synthesis_route | 5 | solvothermal / interfacial / mechanochemical / room-temperature / other（优先级: interfacial > solvothermal > mechanochemical > RT > other） |
| interface_type | 3 | liquid-solid / liquid-liquid / other（含 gas-liquid、air-liquid、none） |
| catalyst | 5 | acetic_acid / PTSA / TFA / Sc(OTf)3_Lewis / none_other（同义词合并: AcOH/HAc/醋酸→acetic_acid） |
| solvent | 7 | dioxane_mesitylene / DCB_BuOH / water_based / DMF_DMSO / acetonitrile / alcohol / other（先标准化: DCB→dichlorobenzene, BuOH→butanol） |
| temperature | 5 箱 | rt(<30°C) / low(30-80) / standard(80-130) / high(130-200) / unknown（正则提取第一个数字，范围取中值） |

**正则解析步骤**：
1. 名称标准化（同义词 → 规范名）
2. 关键词/正则匹配归类
3. 数值提取 + 分箱（temperature）
4. 缺失值 → missing_embedding

**局限性与缓解**：

| 局限 | 严重程度 | 缓解措施 |
|------|---------|---------|
| temperature 数值提取不准（回流/熔融温度混淆、范围取中值失真） | 中 | 分箱 5 类粒度足够粗，精度损失可接受 |
| solvent 混合溶剂归并丢失比例信息（mesitylene/dioxane 1:1 vs 3:1） | 中 | 先标准化名称再归类，比例信息暂不保留 |
| catalyst 浓度信息丢失（6 M vs 3 M acetic acid） | 低 | 分类粒度已足够，浓度差异由模型从数据中学 |
| synthesis_route 边界模糊（room-temp interfacial 归哪类） | 中 | 优先级规则：interfacial > solvothermal > 其他 |
| interface_type 30% 缺失（solvothermal 粉末合成无界面概念） | 中 | missing_embedding 处理 |
| LLM 提取不一致（acetic acid/AcOH/HAc/醋酸混用） | 中 | 正则同义词合并，实现前统计分布验证 |
| 数据库 2 格式可能漂移（同样 prompt 但 LLM 输出可能不同） | 低 | 数据库 2 提取完后先统计分布再应用归并规则 |
