# 2026-05-15 工作总结

## Plan B：化学惩罚项集成

### chem_penalty.py
将四条筛选硬规则连续化为可微违反度 v ∈ [0,1]，训练时作为正则化项注入损失：

```
L_total = L_focal + λ · mean(mask · v)   (mask = pred > 0.5)
```

| 规则 | 违反度函数 | 权重 |
|------|-----------|------|
| 对称性 | CanonicalRankAtoms 全分子对称感知 | 0.5 |
| C2 对位 | 最短路径: 邻位1.0 / 间位0.8 / 对位0 | 0.4 |
| 芳环数 | min(1, (n−4)/6) 连续化 | 0.3 |
| 取代基 | 非卤素取代数/4 | 0.3 |

附带 ViolationCache 缓存类，预计算训练集所有配对违反度，避免每 epoch 重复 RDKit 计算。

### train_pair_predictor_a.py
集成化学惩罚项，新增 `--lambda-chem` 参数 (默认 0.005)。

## λ 消融实验

compare_chem_penalty_ablation.py — 3-fold CV 测试四个 λ 值：

| λ | PR-AUC | Δ vs 基线 |
|---|--------|-----------|
| 0 | 0.6293 | — |
| 0.005 | 0.6308 | +0.0015 |
| 0.01 | 0.6223 | −0.0070 |
| 0.05 | 0.6226 | −0.0067 |

结论：Focal Loss 主导训练，化学惩罚项提升在噪声范围内。λ=0.005 最优但改善不显著。

## 硬规则 ON/OFF 对比

screen_with_gnn.py 新增 `--no-hard-rules` 开关：
- 规则 #0 (苯环) 和 #5 (炔丙基醚) 始终保留
- 规则 #1#2#4#6 可通过开关移除，信任 chem_penalty 在训练中软约束

对比结论：关闭硬规则后模型给违规分子打出更高分（0.967 vs 0.850），
说明软惩罚在训练中未充分抑制违规偏好 → 硬规则现阶段不能移除。

## 关键认知

- λ 不敏感 (0.005 vs 0.01 模型权重完全相同)：Focal Loss 梯度远大于 chem_penalty 梯度
- 加大 λ 反而损害性能 (λ=0.05 PR-AUC 低于基线)
- 模型存在「违规偏好」——关闭硬规则后反而给违规分子高分
- 化学惩罚项的正确方向可能是：训练后排序时施加，而非训练中正则化
