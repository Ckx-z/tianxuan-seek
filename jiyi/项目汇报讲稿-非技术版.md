## 一、我们在做什么（30 秒版）

我们要从**几万种可能的化学分子组合**中，找出**最有可能形成优质二维薄膜的 40 种配方**，推荐给合成化学家去实验验证。

可以把我们的工作理解为：**用计算机替代化学家的部分「试错」工作**——以前合成一个新材料要花一周，现在先用模型筛一遍，只做最有希望的 40 个实验。

## 二、背景：什么是 COF，为什么难？

### 2.1 COF 是什么

**COF**（共价有机框架，Covalent Organic Framework）是一种**二维网状高分子材料**。用日常语言理解：

> 把「单体」想象成乐高积木——有三角形积木（三个连接点），有直线形积木（两个连接点）。
> 三角形 + 直线形 → 拼成一张六边形网（六方晶格）
> 两根直线形 → 拼成一张方格网（四方晶格）

这张网的「网眼」大小约 2-5 纳米（_1 纳米 = 头发丝直径的十万分之一_），可以用来过滤分子、储存气体、或做传感器的基底。

### 2.2 核心挑战

要形成一张**连续、平整、无裂缝**的二维薄膜，需要满足的条件极其苛刻：

| 条件 | 通俗解释 |
|------|----------|
| 反应基团要对位 | 连接点必须在正确的位置（1,4 对位），否则网会「拐弯」 |
| 单体要对称 | 积木的每个连接臂必须完全相同，否则拼不整齐 |
| 苯环为骨架 | 需要刚性六元碳环提供支撑，脂肪链太软撑不住 |
| 取代基不能太多 | 苯环上挂太多「装饰品」会造成空间拥挤，网织不起来 |
| 不能有炔丙基醚 | 一种特定化学结构（醚键旁边有炔基），会干扰反应 |

这些条件不是我们发明的——是化学家几十年的经验总结。**我们的工作是把这些经验写成计算机能执行的规则。**

## 三、我们用的工具箱

在讲数据流程之前，先介绍一下我们用的**计算工具**——就像盖房子需要吊车、搅拌机、水准仪，我们做计算化学筛选也有一套专用工具。

### 3.1 化学信息学工具

| 工具 | 全称/类型 | 做什么 | 通俗类比 |
|------|-----------|--------|----------|
| **RDKit** | 开源化学信息学工具包 | 分子结构解析、SMARTS 子结构搜索、分子指纹生成、化学描述符计算 | 化学家的「万能工具箱」——能画结构、算性质、比相似度 |
| **SMILES** | Simplified Molecular Input Line Entry System | 用字符串表示分子结构的国际标准 | 分子的「身份证号」，一串字符唯一描述一个分子 |
| **SMARTS** | SMILES Arbitrary Target Specification | 在分子中搜索特定化学子结构 | 化学版的「人脸识别」——在分子里找特定部件（如醛基 C=O） |
| **PubChem** | NIH 公开化学数据库 | 化学名称 → 标准结构式的在线查询 | 化学界的「维基百科」，1.1 亿种化合物信息免费查询 |
| **Morgan 指纹 (ECFP)** | Extended Connectivity Fingerprint | 把分子切成片段，编码为定长数字向量 | 分子的「指纹扫描」——每个分子生成独一无二的特征码 |
| **MACCS 指纹** | Molecular ACCess System | 167 种预定义化学子结构的「有/无」编码 | 分子的「体检表」——逐项勾选是否含某官能团 |

### 3.2 量子化学计算工具

| 工具 | 全称/类型 | 做什么 | 通俗类比 |
|------|-----------|--------|----------|
| **xTB** | Extended Tight-Binding | 半经验量子化学计算——近似求解分子电子结构，计算能量、振动频率、键级 | 用简化版量子力学公式估算分子的「稳定性」和「反应活性」，比全量子计算快 1000 倍 |
| **GFN2-xTB** | 第二代几何/频率/非共价扩展紧束缚法 | xTB 的改进版本，专为有机分子优化 | 计算分子间的弱相互作用力（范德华力），判断单体间「匹配度」 |

> **xTB 做了什么**：我们曾用 xTB 计算 15 对精选单体配对的**反应能、堆积能、Wiberg 键级**（衡量化学键强度的指标），试图从第一性原理（_不依赖实验数据，纯计算推导_）判断哪些配对更容易形成稳定的二维网格。
>
> **结果**：xTB 计算出的反应能/堆积能与成膜标签几乎没有相关性。原因可能是——COF 成膜不仅取决于热力学（能量是否降低），更取决于动力学（反应速率、溶剂效应、界面张力等 xTB 算不了的因素）。
>
> **教训**：纯量子化学计算目前还不能替代实验数据驱动的机器学习，但它提供了物理层面的理解——我们知道「为什么这个分子稳定」，即使不能预测「它能不能成膜」。

### 3.3 机器学习 / 深度学习框架

| 工具 | 全称/类型 | 做什么 | 通俗类比 |
|------|-----------|--------|----------|
| **PyTorch** | 深度学习框架 (Meta) | 构建和训练神经网络的基础平台 | 神经网络的「操作系统」——提供张量运算、自动求导、GPU 加速 |
| **PyG** (PyTorch Geometric) | 图神经网络扩展库 | 在 PyTorch 上实现消息传递图神经网络 | 专门处理「关系型数据」的插件——分子图、社交网络、知识图谱 |
| **XGBoost** | eXtreme Gradient Boosting | 梯度提升树——基于表格数据的经典 ML 模型 | 几百棵「决策树」投票——每棵树学会修正前面树的错误，最终组合成强预测器 |
| **scikit-learn** | Python 机器学习库 | 数据预处理、特征选择、交叉验证、评估指标 | ML 的「标准配件包」——训练/测试分割、SMOTE 过采样、ROC/PR 曲线 |

### 3.4 大语言模型 / 文本处理

## 五、数据从哪来（第一、二步详解）

### 4.1 论文结构化提取

我们从 **840+ 篇已发表的 COF 研究论文**中提取信息。但论文是 PDF 格式，机器不能直接理解。

解决方案：用**大语言模型**（LLM，Large Language Model——和 ChatGPT 同类技术）逐篇阅读论文全文，按 21 个字段提取结构化信息。

> **类比**：就像雇了 840 个化学专业研究生，每人读一篇论文，然后填一张标准化的 Excel 表格。但 AI 读一篇只需 30 秒，成本约 0.1 元。

提取的关键字段包括：

| 字段 | 含义 | 示例 |
|------|------|------|
| aldehyde | 醛单体名称 | "1,3,5-三甲酰基间苯三酚" |
| amine | 胺单体名称 | "对苯二胺" |
| film_crystallinity_fluorine | 成膜情况描述 | "形成了自支撑薄膜，结晶度良好" |
| solvent | 溶剂 | "1,4-二氧六环/均三甲苯" |
| temperature | 反应温度 | "120°C" |

### 4.2 从名称到分子结构

论文里写的是**化学名称**（如「1,3,5-三甲酰基间苯三酚」），计算机需要**分子结构**才能计算。

我们做了三个层次的转换：

1. **内置字典**：常见的 ~50 个 COF 单体，预先人工核验了结构
2. **PubChem 数据库**：美国国立卫生研究院维护的公开化学数据库（类似化学界的 Wikipedia），通过名称→CAS号→SMILES 自动查询
3. **SMILES 字符串**：用一串字符描述分子结构的国际标准格式（_可以理解为分子的「身份证号」，如 `O=Cc1c(O)c(C=O)c(O)c1C=O` 就是间苯三酚三甲醛的结构描述_）

### 4.3 单体分类

拿到分子结构后，用 **SMARTS 模式匹配**进行分类：

- **SMARTS**（化学子结构搜索语言）：在分子结构中搜索特定「形状」的查询语言。类似用指纹识别——`[CX3H1](=O)[#6]` 就是「醛基」这个化学官能团的指纹模板。

| 分类维度 | 判定方法 | 说明 |
|----------|----------|------|
| 醛/胺/其他 | SMARTS 匹配醛基 `[CH](=O)` 和伯胺 `[NH2]` | 只有醛和胺能形成亚胺键 COF |
| 反应位点数 | 统计醛基/胺基数量 | C2=两个位点（直线积木）、C3=三个（三角积木）、C4=四个 |
| 含氟 | 检测分子中是否含 F 原子 | 氟能改善薄膜疏水性和结晶度 |
| 含杂环 | 检测环内是否有 N/O/S 原子 | 纯苯环比含氮/氧/硫的杂环更易成膜 |

## 六、两个「判官」：模型如何判断成膜能力（第三步详解）

我们有 487 组已知结果的训练数据（化学家已经在实验中验证过「能成膜」或「不能成膜」的醛+胺配对）。**训练的目标是：让模型学会，给定任意一对新单体，预测它们能否成膜。**

### 6.1 判官一：XGBoost（经验丰富的化学家）

**XGBoost**（eXtreme Gradient Boosting，极端梯度提升）是一种经典的**表格数据模型**。

**工作原理**（用医院体检类比）：

> 医生判断一个人是否健康，会查各项指标：血压、血糖、胆固醇、心率……
> XGBoost 就像一个经验丰富的医生：它看的是我们提前算好的 **~2000 个分子指标**。

这些指标包括：

| 指标类型 | 数量 | 通俗解释 |
|----------|------|----------|
| Morgan 指纹 | 2048 维 | 把分子切成很多小片段，统计每种片段出现多少次——类似「分子版脸盲测试」 |
| MACCS 指纹 | 167 维 | 另一种片段编码，侧重官能团（化学活性部件） |
| 分子描述符 | 24 维 | 分子量、脂溶性、氢键供体/受体数等——类似分子的「身高体重体脂率」 |

XGBoost 学习的是：「分子量在 200-400 之间 + 含氟 + 醛基数 ≥ 3」→ 高分；「分子量 > 800 + 无苯环」→ 低分。

- **优点**：训练快（几分钟），结果稳定，可解释性好（能明确知道哪个指标贡献最大）
- **缺点**：只能看我们给它的指标，无法自己发现新规律

**模型表现**：PR-AUC = 0.654

> **PR-AUC 是什么**（Precision-Recall Area Under Curve）：精确率-召回率曲线下面积。通俗理解——模型挑出「真正会成膜」的组合而不漏掉好组合、也不把坏组合误判为好组合的综合能力。满分 1.0，随机猜 0.5。0.654 意味着模型有中等偏上的预测能力，但离完美还有距离。

### 6.2 判官二：GNN（从分子结构自学的学徒）

**GNN**（Graph Neural Network，图神经网络）是一种**深度学习模型**，专门处理图结构数据。

**为什么需要 GNN？**

分子本质上是一个「图」（Graph）——原子是节点，化学键是边：

```
    O
    ‖
H — C — C — C — C — H
            |
            H
```

XGBoost 通过「统计小片段」来理解这个图。但有些信息统计片段会丢失——比如「两个醛基在苯环的对位还是间位」，这对于 COF 至关重要。

GNN 直接读整个分子图，通过**消息传递机制**（_每个原子把自己的信息告诉邻居，邻居再告诉邻居的邻居，反复 3 轮，最终每个原子都「知道」了整个分子的大致结构_），自动学习哪些子结构对成膜有利。

> **类比**：
> - XGBoost = 看验血报告诊断疾病的医生（只看指标数值）
> - GNN = 看 X 光片诊断疾病的医生（看整体结构图像）

**模型表现**：PR-AUC = 0.731 ± 0.067（5 折交叉验证）

> **5 折交叉验证**：把 487 条数据分成 5 份，每次用 4 份训练、1 份考试，轮换 5 次取平均。防止模型「背答案」——真正学到规律应该在没见过的数据上也考得好。

**±0.067**：5 次考试的成绩有波动（最低 0.697，最高 0.835），但平均 0.731 比 XGBoost 高了约 8 个百分点——**GNN 确实从分子图中捕捉到了 XGBoost 抓不住的规律。**

### 6.3 双模型联合：1+1 > 2

我们采用**联合打分**而非单一模型：

**联合公式**：`最终得分 = 60% × GNN + 40% × XGB − 10% × |GNN − XGB|`

| 项 | 含义 |
|----|------|
| 60% GNN | GNN 权重更高（更准） |
| 40% XGB | XGB 作为保守的「第二意见」 |
| −10% × 分歧 | **分歧惩罚**：如果两个模型意见严重不一致，扣分 |
| | → 鼓励选「两个模型都同意的高分」组合 |

> **直觉**：就像两个专家给项目打分。两人都说 9 分 → 靠谱；一人说 9 分一人说 2 分 → 说明存在不确定性，先不选。

## 七、化学规则：计算机不是最终裁判（第四步核心）

模型只能给出概率分数，**不能替代化学定律**。我们在模型打分之后，还施加了 **6 项化学硬规则**逐对审核。不满足任意一项的配对**直接淘汰**，模型分数再高也没用。

### 规则总表

| 编号 | 规则 | 通俗解释 | 排除了多少 |
|------|------|----------|-----------|
| #0 | 必须有苯环 | 没有六元碳环当骨架，膜撑不起来 | 94 个单体 |
| #1 | 芳环数 ≤ 4 | 太大太复杂的分子有空间位阻，排不进网格 | 146 个单体 |
| #2 | 反应位点必须对称 | 连接臂必须等长，否则拼出不规则形状 | 344 个单体 |
| #3 | ≥2 个反应位点 | 两个连接点是织网的最低要求 | — |
| #4 | C2 单体必须是对位 | 两个连接点必须是「对面」(1,4位)，邻位/间位导致网弯折 | 53 个单体 |
| #5 | 不能含炔丙基醚 | 一种不稳定的化学结构，醚+炔基共存会干扰反应 | 1 个单体 |
| #6 | C2 取代基限制 | 苯环上最多挂 4 个非氢装饰。超过 4 个的，多余的只能是氟氯溴碘 | — |

### 规则 #2 详解（最关键的一个）

**问题**：怎么判断一个分子是否对称？

分子有「全局对称性」——两个连接臂如果化学环境不同，连接时就一个快一个慢，形成不规则结构。

我们最初用 **Morgan 指纹**（一种基于局部环境的方法）判断对称性，结果出了严重错误：**把所有对位二取代苯胺都误判为「对称」**。

原因：Morgan 指纹的「视野」是半径 2 键——而对位取代基在苯环上相距 4 键，超出了视野。

**修复**：改用 RDKit 内置的 **CanonicalRankAtoms**（全分子拓扑对称感知）算法，它能「看到」整个分子的对称性。修复后对称检测的准确率从「几乎全部误判」提升到「化学上正确」。

> **教训**：即使是看起来简单的化学规则，也需要用对工具。错误的规则比没有规则更糟糕。

## 八、筛选全流程：从 40 万对到 40 对

```
所有可用的醛单体 (~300 个) × 所有可用的胺单体 (~400 个)
                    │
        ≈ 120,000 种理论组合
                    │
    ┌───────────────┼───────────────┐
    │ 经济性：只交叉配氟                    │
    │ 含氟醛 × 非含氟胺 + 非含氟醛 × 含氟胺  │
    ▼                                       │
    ≈ 30,000 种合理组合                       │
    │                                       │
    ├─ 规则 #0-#6 化学审查 ─────────────────┤
    │  淘汰不含苯环、不对称、非对位等        │
    ▼                                       │
    ~8,000 种化学合理的配对                   │
    │                                       │
    ├─ GNN 前向传播 ────────────────────────┤
    ├─ XGBoost 预测 ────────────────────────┤
    │  两部模型各打一个分                     │
    ▼                                       │
    联合评分 → 排序                           │
    │                                       │
    ├─ 分层选取策略 ────────────────────────┤
    │  35% 给「大胺小醛」(三角胺+直线醛)      │
    │  25% 给「大醛小胺」(三角醛+直线胺)      │
    │  40% 给其他合理组合                     │
    ▼                                       │
    Top 40 推荐清单                           │
```

### 分层选取的逻辑

化学直觉：「大胺小醛」（C3-胺批量 + C2-醛批量）和「大醛小胺」（C3-醛批量 + C2-胺批量）都能形成六方网格，但化学性质不同。不该让一种类型垄断 Top 40。

我们设定：
- **C3-胺配对 ×1.15 加成**（补偿训练数据中 C3 胺只有 C2 胺的 1/7 的偏差）
- **C3-醛配对 ×1.10 加成**

> **类比**：高考录取时给少数民族加分，不是因为少数民族学生「更好」，而是因为历史资源不均衡导致起跑线不同。C3/C2 加成同理——训练数据偏少导致模型低估，需要手动补偿。

## 九、最终结果

### 9.1 Top 40 组成

| 特征 | 数量 |
|------|------|
| 六方晶格 (hcb) | ~22 对 |
| 四方晶格 (sql) | ~18 对 |
| 含氟配对 | ~15 对 |
| C3-胺（大胺小醛）主导 | ~14 对 |
| 最优醛单体 | 三甲酰基三甲氧基苯、三甲酰基间苯三酚 |
| 最优胺单体 | TAPB 衍生物（三臂芳香胺） |

### 9.2 关键发现

1. **「大胺小醛」是主流模式**：C3 胺（分子量 350-600）+ C2 醛（分子量 150-250）的组合占主导——大的三角形积木 + 小的直线连接件更容易形成规整网格
2. **纯苯环 > 杂环**：含氮/氧/硫的杂环比纯苯环成膜概率低约 15%
3. **氟 ≠ 万能**：含氟单体不是越多越好——最佳结果中非氟配对也占据重要比例
4. **双模型一致性是关键信号**：两个模型都打高分的配对，在化学结构上也最合理

## 十、术语速查表

| 术语 | 全称 | 通俗解释 |
|------|------|----------|
| COF | Covalent Organic Framework | 二维网状有机高分子，像分子级蕾丝 |
| SMILES | Simplified Molecular Input Line Entry System | 分子结构的字符串表示法 |
| SMARTS | SMILES Arbitrary Target Specification | 化学子结构搜索模式，类似正则表达式 |
| GNN | Graph Neural Network | 图神经网络——直接「看」分子结构的深度学习模型 |
| XGBoost | eXtreme Gradient Boosting | 一种树模型集成算法——基于统计指标的决策树组合 |
| PR-AUC | Precision-Recall Area Under Curve | 模型预测能力的综合评分（0.5=乱猜，1.0=完美） |
| ECFP/Morgan | Extended Connectivity Fingerprint | 把分子切成片段编码为定长向量的方法 |
| C2/C3/C4 | — | 单体反应位点数：2 个（直线）、3 个（三角）、4 个（十字） |
| 对位 para | — | 苯环上两个取代基位于 1,4 位置（对面），距离最远 |
| 间位 meta | — | 1,3 位置，会导致网格拐弯 |
| 邻位 ortho | — | 1,2 位置，会导致网格急转 |
| Bilinear | — | 双线性交互层——让醛和胺的特征不是简单相加而是「相乘交互」 |
| 交叉验证 CV | Cross-Validation | 训练考试轮换，防止背诵答案的验证方法 |
| 分层选取 | Stratified Selection | 确保不同类型都有代表入选，而非一种类型霸榜 |
