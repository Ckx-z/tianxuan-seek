# Phase 4 化学正则化 — 工作总结

## 设计哲学

化学正则化的目的是提供**最基础的化学常识**作为训练弱信号，而非替代模型做判断。

核心原则：**信任模型**。3.2M 参数 GNN + 交叉注意力 + 原子对交互，表达能力足够学到溶解性匹配、刚性互补、共轭效应等模式。规则只保留几乎无例外的化学硬事实。

## 规则演变

### 初始设计 (05-25): 5 条单体级

苯环必需 / 官能团对称 / C2 对位 / 芳香复杂度 / 取代基限制

### 扩展 (05-27): 9 条 (5 单体 + 4 配对)

新增溶解性匹配 / 刚性匹配 / 共轭匹配 / 位阻匹配（从 Phase 6 配对策略提前）

### 精简: 8 条

删除芳香复杂度 (rings) — 90% 样本违反，无区分度，与 phenyl 重复。

### 最终: 3 条

删除取代基限制、溶解性、刚性、共轭、位阻 — 全部交给 GNN 自己学。

## 最终 3 条规则

| # | 规则 | 可微形式 | 原因 |
|---|------|---------|------|
| 1 | 苯环必需 | `(1 - min(n_phenyl, 1)) x prob` | COF 成膜必须有芳环，几乎无例外 |
| 2 | 官能团对称 | `max(0, 0.5 - fg_symmetry) x prob` | C2/C3 官能团必须对称，几何硬要求 |
| 3 | C2 对位 | `is_c2 x (1 - is_para) x prob` | C2 必须对位，否则无法形成二维网络 |

## 设计细节

- **只罚假阳性**：违反规则但预测成膜 → 罚。不罚假阴性
- **梯度回传**：`penalty = violation x prob`，梯度通过 prob 回传到 GNN
- **Warm-up**：前 50% epochs lambda=0, 50%-80% 线性增加, 最后 20% 恒定 lambda=0.005
- **ViolationCache**：预计算训练集所有配对的违反度，避免每 epoch 重复 RDKit 计算

## 全量违反统计 (2,268 组)

| 规则 | mean | nonzero |
|------|------|---------|
| phenyl | 0.276 | 27.6% |
| symmetry | 0.522 | 52.2% |
| para | 0.129 | 14.3% |
| **加权总和** | **0.652** | **85.9%** |

## 删除规则的原因

| 删除的规则 | 原因 |
|-----------|------|
| 芳香复杂度 (rings) | 90% 样本违反，COF 单体本来就有芳环，无区分度 |
| 取代基限制 | -F vs -tBu 位阻差异巨大但规则同等对待，不合理 |
| 溶解性匹配 | LogP 不等于 COF 真实溶剂体系，且 GNN 应自己学 |
| 刚性匹配 | 阈值经验性强，刚+柔是正常 COF 组合不应降权 |
| 共轭匹配 | 布尔判断梯度为零，GNN 应自己学 |
| 位阻匹配 | 73% nonzero，COF 单体反应位点周围普遍有取代基 |

## 关键决策

1. **化学正则化不等于规则引擎**：规则越精细越容易和数据冲突
2. **模型就是最大的化学知识库**：如果 3.2M 参数 GNN 学不到化学兼容性，加规则也补不回来
3. **Phase 6 完全信任模型**：只保留拓扑硬约束，无软约束 tiebreaker
