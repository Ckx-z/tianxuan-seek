# COF 知识图谱交互式可视化 — 使用教程

## 快速开始

用浏览器打开以下任一 HTML 文件即可：

| 文件 | 内容 | 用途 |
|------|------|------|
| `graph_visual.html` | 全量图 (78 节点/255 边) | 预测配对 + 文献边全景 |
| `graph_visual_core.html` | 核心图 (69 节点/212 边) | 纯 Top 250 预测边网络 |

**无需服务器**，双击 HTML 文件直接在浏览器中运行。

## 重新生成

```bash
python graphrag图谱辅助/visualize.py
```

依赖数据文件：
- `graph.gml` + `graph_nodes.json` — 知识图谱结构
- `data/structured/*.yaml` — 文献结构化信息
- `data/processed/screening_top40_with_hard_full.csv` — GNN 预测结果
- `data/processed/commercial_monomers_classified.csv` — 商业单体库

修改 `visualize.py` 顶部常量可调整参数：

```python
PREDICTED_EDGE_N = 250   # 预测边 Top N (改这里控制图规模)
SVG_SIZE_FULL = (200, 130)
SVG_SIZE_CORE = (260, 170)
```

生成后放 PDF 到 `data/pdfs/` 目录，文献来源会自动关联 PDF 路径。

## 搜索功能

在右侧搜索框输入关键词或快捷命令，支持：

### 文本搜索

直接输入 SMILES、化学名、CAS 号、单体类型等关键词，模糊匹配。

### 快捷命令

| 命令 | 效果 | 示例 |
|------|------|------|
| `f:yes` | 含氟单体 | 直接输入 `f:yes` |
| `f:no` | 非含氟单体 | `f:no` |
| `comm:yes` | 商业单体 | `comm:yes` |
| `n:yes` | 含 N 杂环单体 | `n:yes` |
| `type:aldehyde` | 醛单体 | `type:aldehyde` |
| `type:amine` | 胺单体 | `type:amine` |
| `topo:C2` | 拓扑 = C2 | `topo:C1` ~ `topo:C4` |
| `film:0` | 成膜率 = 0 | `film:0` |

### 搜索结果

- 列表展示匹配单体，含文献数、成膜率、F/N 标签
- 商业单体带有 **商业** 绿色标签
- 点击结果 → 详情面板 + 图谱聚焦 + 高亮关联节点

## 详情面板

### 单体详情

- **化学结构图**：RDKit 生成的 2D SVG 结构式
- **基本属性**：类型、拓扑、含氟、N 杂环、芳环数、分子量、文献数、成膜率
- **商业单体**额外显示：名称、CAS 号、商业标签
- **预测配对 Top 3**：GNN 预测的最佳配对单体，按 margin 降序
  - 金色边框节点 = Top 3 配对在图中高亮
  - 点击可跳转查看该配对单体详情
- **来源文章列表**：单体出现在哪些文献中
  - 点击某篇文章 → 展示完整 22 字段结构化信息
  - 每篇文章下方标注 PDF 路径 (`data/pdfs/{id}.pdf`)

### 文献详情（点击来源文章后）

展示 22 个字段：
期刊、研究体系、试剂/单体、催化剂、溶剂、反应温度、合成模式、
合成路线、界面类型、退火条件、席夫碱动力学、氟效应、含氟单体、
成膜/结晶度/氟、吸附机理、计算方法、实验结论 (1-3)、创新点、表征方法、
PDF 文件

点击「返回」回到单体详情。

## 图谱交互

| 操作 | 效果 |
|------|------|
| **点击节点** | 打开详情面板，节点红色边框高亮 |
| **选中单体后** | Top 3 预测配对单体金色边框高亮 |
| **搜索** | 匹配节点高亮，其余暗淡 |
| **滚轮缩放** | 放大/缩小视图 |
| **拖拽** | 平移视图 (拖拽时边自动隐藏) |
| **折叠搜索面板** | 点击 `◀ 搜索` 按钮，图谱全屏 |

## 命令行查询

除可视化外，也可用 Python 脚本查询图数据：

```bash
python graphrag图谱辅助/query_graph.py   # 交互式查询
python graphrag图谱辅助/graph_stats.py   # 统计分析报告
python graphrag图谱辅助/build_graph.py   # 重新构建图谱
```
